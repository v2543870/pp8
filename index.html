Мета роботи

Налаштувати підключення до MongoDB Atlas, створити схему Mongoose, виконати основні операції з даними та застосувати агрегаційний пайплайн.

Структура проєкту: models/Task.js (схема), controllers/TaskController.js (логіка), demo.js (підключення та демонстрація).

Завдання 2. CRUD

CREATE: createTask(data)

async function createTask(data) {
  return await Task.create(data);
}

READ: getAllTasks()

async function getAllTasks() {
  return await Task.find().sort({ createdAt: -1 });
}

READ: getTaskById(id)

async function getTaskById(id) {
  return await Task.findById(id);
}

READ: getTasksByStatus(status)

async function getTasksByStatus(status) {
  return await Task.find({ status }).sort({ createdAt: -1 });
}

UPDATE: updateTask(id, updateData)

async function updateTask(id, updateData) {
  return await Task.findByIdAndUpdate(id, updateData, {
    new: true,
    runValidators: true,
  });
}

UPDATE: markAsCompleted(id)

async function markAsCompleted(id) {
  return await updateTask(id, { status: "completed" });
}

DELETE: deleteTask(id)

async function deleteTask(id) {
  return await Task.findByIdAndDelete(id);
}

Завдання 3. Агрегація: getTasksSummary()

const groups = await Task.aggregate([
  { $group: { _id: "$status", count: { $sum: 1 } } },

Результат повертається як об’єкт із кількістю завершених, незавершених та загальною кількістю справ.
